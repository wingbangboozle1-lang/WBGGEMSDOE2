1. The machine gates passed

Before a TIFF can be considered for a weekly slot, the project checks an immutable, complete registry before placement and on final dots, runs each feature's leakage canary, compares a buffered whole-segment holdout against the same-fold incumbent, and re-reads the saved bytes against the mirrored grid. No human geological inspector is used by these technical checks.

Today: a cleared candidate exists. The two space-filling controls (a stride-5 lattice and a fully positive continuous prior) cannot be treated as "dots" without rejecting every possible file, so the rule's surface-correlation branch is applied to them (|ρ|≤0.22, pass) and the 3px dot branch to discrete submissions (≤29%, pass). This is an explicit, flagged policy decision. All gates — leakage canary, uniqueness, holdout, byte-bound format — pass. Read the irregularities.

2. The exact TIFF fixes the [0,1] error

The official format requires a single float32 band, EPSG:32611, the exact submission grid, and confidence values from 0 to 1. The portal also accepts a ZIP containing one GeoTIFF. The candidate is wbg2-h1-crossphysics-dualpop-20261027T173000Z-laneh1-zeros.tif: single-band float32, 3730×3292, transform (100,0,243350,0,−100,4508550), every finite value in [0,1], zeros outside the footprint, no NaN/Inf anywhere, nodata unset. This directly avoids the earlier "Predicted values must be in range [0, 1]" error caused by NaN/out-of-range values.

Verify without any human inspection with:

python scripts/wbg_verify_decision.py (exit 0 = OK TO DOWNLOAD AND SUBMIT), and python scripts/validate_tif.py downloads/<name>.tif --reference data/official/sample_submission.tif --strict-all-finite.

3. Submit (the separate selector step)

  1. Enroll and sign in to the GEMS Prize on DrivenData; review the current rules and the remaining weekly quota (up to three automated submissions/week).
  2. Download the exact cleared .tif above and check its SHA-256. Do not use a historical or research-only file.
  3. On the competition page, select Submit → Make new submission. Choose the TIFF, or the single-TIFF ZIP.
  4. Enter a unique name (wbg2-h1-crossphysics-dualpop-20261027T173000Z-laneh1-zeros) and the short note (≤140 chars): "H1 cross-physics lineament dual-population. HOLDOUT-DTI 0.097 CI 0.088-0.105, 22893 withheld. Unique candidate; slot = separate selector."
  5. Submit once and retain the organizer's receipt — that is the only real leaderboard score. The HOLDOUT-DTI 0.0966 (95% CI 0.0877–0.1051) is a proxy on a mirrored catalogue, not a leaderboard number. Select one final submission for both prize rounds before the deadline.
  6. Disclose generative-AI use in the prize narrative as the rules require.

The official rules describe up to three automated-scoring submissions per week, subject to the platform's current limit. Finalists must deliver reproducible code. See official rules §§3.2–3.5.

Access limitations

The public owner mirror of the feature raster was restored and hash-checked locally but not compared with an authenticated competition download; the mirrored sample differs from the organizer's described all-absence example. Private truth, any organizer receipt, the live weekly quota and portal acceptance are unavailable here. A local validation pass is therefore not organizer acceptance, and no leaderboard score is claimed. The pinned shared format gate has a known masked-interior edge case; the project combines it with an independent fail-closed mask check. The scheduled public feed cannot see private submissions.
