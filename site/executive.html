1. Wait for the machine gates

Before a TIFF can be considered for a weekly slot, the project must check an immutable complete registry before placement and on final dots, run each feature's leakage canary, compare a buffered whole-segment holdout against the same-fold incumbent, and re-read the saved bytes against an authenticated organizer template. A paired confidence interval must support an improvement. The selector then checks the current quota. No human geological inspector is used by these technical checks.

2. Check the exact TIFF

The official format requires a single float32 band, EPSG:32611, the exact submission grid, and confidence values from 0 to 1. The portal also accepts a ZIP containing one GeoTIFF. The official problem description calls for null/NaN outside bounds; our optional strict whole-array finite check is a diagnostic, not a substitute for organizer guidance.

With an authenticated official template in place, the local command is:

python scripts/validate_tif.py candidate.tif --reference /path/to/official_template.tif

To additionally detect any non-finite or out-of-range cell anywhere, add --strict-all-finite. The command does not clip or silently change values. A successful report says only “format valid against reference”; it never approves a slot or guarantees portal acceptance.

The previous “Predicted values must be in range [0, 1]” error cannot be diagnosed without the actual rejected bytes. A NaN, infinity, negative value, or value above one can each require investigation. Do not assume that a zero-filled exterior is necessarily accepted or compliant.

Access limitations

The public owner mirror of the feature raster was restored and hash checked locally, but it has not been compared with an authenticated competition download. The mirrored sample differs from the organizer's described all-absence sample; 19 label-free raw bands were cached and 22 derived features built. The registry is an accessible-public inventory (126 files, 8 unresolved ledger rows, HEAD snapshots), not organizer-complete. Private truth, per-file receipts, account quota and organizer acceptance remain unavailable. The pinned shared format gate has a known masked-interior edge case; the separate local check adds a stop but does not fix the upstream tool. The scheduled public feed cannot see private submissions.
