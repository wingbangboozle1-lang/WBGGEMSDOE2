# Project working agreement

At the start of each session read `README.md`, `research/findings.md` and `evidence/run_card.json`. Treat the preserved original prompt as historical context, not as evidence or perpetual authorization. Respect the active branch and current higher-priority instructions.

- No real competition slot without the separate selector; no copies disguised as novel predictions.
- Enforce the literal duplicate stop against **every** registry raster before placement and on final dots; an incomplete registry cannot prove uniqueness.
- Reuse the pinned shared template; derive catalogue features from visible faults only for each spatial holdout. Run single-feature leakage canaries. Label scores and confidence intervals accurately.
- Do not call a leaderboard projection or user claim an organizer receipt. No auto-repair of a candidate's values.
- Keep data and large generated assets out of Git, and document sources, rights, hashes, limitations and negative results.
- If evidence, data access or policy blocks completion, say so and fail closed instead of fabricating a candidate.
