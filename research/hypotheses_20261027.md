## Why the top candidate should be validated before a slot

The official metric is recall-dominated (α = 0.2, β = 0.8, 300 m triangular kernel —
[problem description](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/#performance-metric)),
so a plausible-looking geological story is not enough: a new surface must beat a
matched control on identically buffered, whole-component, spatially blocked folds.
We therefore preregister the three arms above, run single-feature leakage canaries,
and report pooled HOLDOUT-DTI with a paired spatial-block 95% CI. A holdout win is
still only a proxy; no new file is uploaded by this repository. The selector step
and the current weekly cap (staff say the submission page's displayed limit
prevails — [DrivenData staff, 5 Oct 2026](https://community.drivendata.org/t/submission-amount-question/11553))
remain with the human.
