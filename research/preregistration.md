## Frozen safety protocol

- Use the shared, pinned template’s cached layers, `evaluate_holdout.py` and `submission_writer.py`; no private metric or writer fork. Inputs must be hash checked, and a mirror hash is **not** evidence that the organizer produced those bytes.
- Hide whole connected fault segments with spatial buffer; rebuild every catalogue-derived input using the visible mask; score only the active footprint, masking visible faults pixel-exactly. Use pooled distance-weighted Tversky (α 0.2, β 0.8, triangular 300 m kernel) with a spatial-block confidence interval, and publish withheld-positive count, evaluator version and hashes.
- Assess every feature individually as a leakage canary; oriented AUC over 0.90 stops interpretation until independently explained.
- Surface-rank correlation above 0.90 or more than 70% of candidate dots within 3 pixels of **any** registry raster is a duplicate stop. Do not exempt calibration lattices, change thresholds, or disguise an existing prediction with a new name. Report actual registry coverage and limitations.
- Candidate performance must exceed the current best **on the same evaluator and folds**, including paired uncertainty, before a separate selector may consider any weekly slot. Do not equate catalogue-recovery holdout to hidden-label leaderboard performance.
- Exactly matching CRS, transform, shape, one float32 band, finite in-footprint values in [0,1], and saved-byte/ZIP checks are necessary but never sufficient. An all-finite encoding is a local precaution, not proof of portal acceptance. The organizer’s wording on outside-bounds nulls must also be respected.
- Before placement, test mathematical feasibility of a 37,654-dot budget (matching the historical H33-B2 file) against the registered 5-pixel calibration lattice. This feasibility calculation was already performed as a preliminary audit before this plan was written, not a blinded scientific test. If the lower bound already exceeds 70%, the candidate is duplicate by construction; stop without generating dots or a TIFF. This does not prove that smaller candidates are impossible. The negative result is not an authorization.

### Post-plan feasibility finding

The independent audit subsequently located a stronger witness, the registered `17GEMSDOE_E-proba-multiscale` raster. It is a **continuous probability surface**, not a conventional sparse dot map; however, the pinned shared literal gate defines support as all finite values greater than zero. This raster is positive on every valid footprint cell. With that definition, *every nonempty* candidate overlaps the reference by 100% within 3 pixels, so the rule is mathematically infeasible for any nonempty candidate. See [the measured certificate](../evidence/shared_tool_checks.json), [the raster audit](../evidence/portfolio_audit.json), and [the run card](../evidence/run_card.json). This is not a finding of geological plagiarism. A different treatment of dense surfaces and calibration grids would require an authorized protocol change; no exemption has been silently applied.
