Step 2 · Exact 6-Step DrivenData Upload Checklist

Portal Workflow
  1. Check Weekly Slot Budget (Max 3 / 7 days): Sign in at DrivenData Submissions ↗ and confirm remaining rolling weekly uploads before uploading any file.
  2. Download the All-Finite -zeros.tif File (or .zip if portal requests compressed upload): Never upload a -nan.tif or -nanoutside.tif file.
