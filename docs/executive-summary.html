How to submit, when approved

No file is currently eligible. These steps do not authorize the historical references.

Currently locked
  1. Check the decision first. A new candidate must pass the surface and final-dot registry checks, every leakage canary, a comparable blocked holdout, and byte-bound format validation. Promotion to a weekly slot is a separate selector step.
  2. Download the exact approved file. Use the future candidate's single-band GeoTIFF or a ZIP containing only that GeoTIFF. Verify its SHA-256 against its receipt. There is no approved file to download today.
  3. Confirm the local format receipt. The official page requires EPSG:32611, 100 m, matching shape and transform, one float32 layer and values in [0,1]. The pinned shared gate has a known finite-NoData-in-footprint gap; our supplemental check blocks it but the upstream tool still needs a fix. Our conservative all-finite check is not proof that zero-outside meets the official null/NaN wording or that the portal will accept it.
  4. Open DrivenData. Sign in, enroll, choose Submit → Make new submission, select the approved file and enter the byte-bound short note (at most 140 characters for this project). Check the actual remaining weekly allowance on the submission page.
  5. Keep the receipt. Record the exact filename, hash, note, timestamp and organizer result. A local HOLDOUT-DTI or an unvalidated projection is never a live score.

Why the gate is blocked

Two independently reopened prior files.

Binary lattice witness. 5,160,724 of 5,167,373 footprint cells are within three pixels of a registered lattice dot. Only 6,649 are outside. For 37,654 distinct in-footprint dots, the minimum possible overlap is 82.34%, above the 70% limit.

Continuous-prior witness. The shared literal implementation counts any finite positive prior pixel as support. A registered continuous prior is positive across the entire footprint. Under that implementation every nonempty candidate overlaps it completely; whether a continuous field should count as “dots” is unresolved, not silently exempted.
