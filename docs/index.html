Why B2 may have performed well — cautious interpretation

The official metric gives distance-weighted partial credit around mapped fault pixels: alpha 0.2, beta 0.8 and a 300 m triangular kernel. This setup makes near-fault predictions useful and penalizes missed labelled faults more heavily than false positives. A fault-continuation / catalogue-adjacent predictor could therefore perform well on recovery of expert-mapped faults. This is a plausible metric-based explanation only. Without private evaluation labels, exact uploaded bytes, an organizer receipt, a shared evaluator, and an ablation, causation is unverified. It cannot establish discovery of new geothermal vents.

How a future submission must be cleared

  1. Restore authenticated competition inputs, the exact template, the shared feature stack, holdout evaluator and writer. Do not invent replacements.
  2. Record one lane and preregister one hypothesis. Use buffered whole-segment hide-and-recover; derive catalogue features only from visible segments and mask visible positives pixel-exactly.
  3. Run each feature-only leakage canary. Stop if unexplained AUC exceeds 0.90.
  4. Check the proposed surface against a dated, complete registry before dot placement; stop on |Spearman| > 0.90 or >70% 3-pixel overlap against any one raster. Repeat against the final raster/dots.
  5. Require a pooled HOLDOUT-DTI result with evaluator ID, withheld positive count and 95% CI, improving on the current same-evaluator best under the preregistered rule.
  6. Validate the exact saved TIFF against the official sample grid: one float32 band, exact CRS/shape/transform, finite values in [0,1], and no NaN inside the footprint. Preserve the SHA-256 and JSON run card.
  7. Only the separate selector can authorize a live slot. Check the current portal cap, submit manually while authenticated, and save the actual organizer receipt. This repository cannot log in or submit.

Automated file-format checker: validate_submission.py. It requires the actual candidate and reference TIF and emits a JSON receipt. A format PASS never means submission approved.
