1. The question: why did h33-h33-2-b2 score 0.2778, and can we beat it?

Provenance of that number. The value is owner-reported from the submission page; no organizer receipt tying those exact bytes to that score is stored in any of the sites or here. The file is gemsdoe32-h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros.tif (219,065 bytes). The GEMSDOE32 site's own ledger records it as “GROUP BEST. == solo minus 2545 dots within 2px of catalogue; projection was 0.2747”, and the sites' byte audits show the GEMSDOE25/30 d2.8 mask is identical inside the footprint, so B2 is that mask with 44,090 → 37,654 dots.

Why it scores. The official metric is DTI = TPw / (TPw + 0.2·FPw + 0.8·FNw) with a 300 m triangular kernel and 100 m cells, so a false negative costs four times a false positive and a prediction within 3 px of a truth pixel costs nothing at all. Three consequences follow, and B2 satisfies all three: (i) the emitted mass is small (37,654 cells ≈ 0.73 % of the 5,167,373-cell footprint), so FPw stays bounded; (ii) the mass sits where a structural/scarp prior is strongest, which is where expert-mapped faults concentrate; (iii) mass on already-mapped pixels is masked out of the score, so pruning the 1–2 px collar around the catalogue removes cost without losing credit.

What it implies arithmetically. With F = |G| the hidden fault pixels and FPw ∈ [0, mass], the reported 0.2778 requires TPw ≥ 0.235·F (if FPw = 0) and TPw ≈ 0.27·F (if FPw = mass). If the experts' new-fault set has roughly the same pixel count as the catalogue (60,988), that is 14,300–16,600 recovered fault pixels, i.e. 23–27 % of the hidden truth. This is an identity rearrangement of the official formula, not a measurement of the leaderboard.

Can we beat it? Beating 0.2778 needs TPw ≥ 24,400 at modest FP — about 40 % of the hidden truth — which no dot-pattern filter can reach: it requires a detector that fires on faults the catalogue does not contain. That is the design target of this lane. Whether the file above reaches it is not established; what is established is its held-out behaviour and its measured similarity to the registry (below).

3. Method: hide-and-recover on whole fault components

  • Folds. The catalogue's 3,191 connected fault components are assigned by centroid to the four quadrants of the footprint; every fold withholds whole components (29,328 / 12,571 / 9,643 / 9,438 px, 60,980 px total) plus a 3 px buffer.
  • No catalogue peeking. Every catalogue-derived feature is rebuilt from visible components only, and the scorer masks visible faults pixel-exactly, so withheld faults stay active and can be credited.
  • Features. 47 candidate features: lidar scarp morphology (10 bands + polarity + multi-scale smoothing + gradients), GeoDAWN radiometrics and ratio/TMI-extension layers, structure-tensor coherence/orientation, distance to the SGMC fault map, spring and geothermometry densities, and (in the “full” variant only) distance/density/along-strike-continuation of visible faults.
  • Leakage canaries. Each feature alone on a holdout: maximum AUC 0.8569 (D_vis_log), 0 feature(s) above the 0.90 stop. No leakage flag.
  • Model and operating point. Gradient-boosted trees (scikit-learn HistGradientBoostingClassifier); the emitted set is the top-k model scores over the scoring footprint, i.e. the operating point is chosen on the pooled DTI curve rather than an arbitrary 0.5 probability cut.

Negative result that changes the design. The same model with catalogue-proximity features (distance to visible faults, visible-fault density, along-strike continuation from the catalogue) scored HOLDOUT-DTI 0.0156 — essentially zero. Under hide-and-recover, “be near the mapped catalogue” is not a fault detector: it re-detects the faults that were not withheld and earns no credit for the withheld ones. This is why the emitted file uses the geophysics-only (“blind”) feature set, and it is direct evidence against the assumption that dots hugging the catalogue are valuable.

No defensible point estimate exists, and this was measured rather than assumed. Scoring 38 registry rasters on the identical folds gives Spearman +0.251 between same-fold HOLDOUT-DTI and the reported leaderboard value, with a linear fit whose leave-one-out R² is -0.055 (RMSE 0.095). A fit with negative out-of-sample R² has no predictive value, so the naive projection it would produce (0.207) is not reported as an estimate. Conditional arithmetic instead: at 66,383 emitted cells the DTI identity gives, for a new-fault truth of F pixels and hit fraction h, DTI = hF /(hF + 0.2·FP + 0.8·(1−h)F). With the 23–27 % hit fraction the 0.2778 file's own algebra implies and FP ≈ 60 % of mass, this file lands near 0.10–0.20; if its geophysical coverage transfers better than the dot family's, near 0.26–0.31. That is a projection under stated assumptions, not a score.

6. Duplicate / novelty gate

Rank-correlation gate: PASS. Against all 93 fetched registry rasters the largest |Spearman| is 0.565 (limit 0.90), and the largest share of this file's cells within 3 px of any single raster is 99.84 %.
The literal 3 px rule is unsatisfiable, and that is measured, not asserted. The fetched registry contains the GEMSDOE13 stride-5 lattice (206,895 cells, 4.0 % of the footprint), which places every footprint cell within 300 m of a lattice cell. Organizer-accepted files fail the same 70 % test identically: B2 99.91 %, d2.8 99.92 %, h36-1 99.91 %, this file 99.84 %. The file is therefore no more similar to that witness than the accepted top scorers are; no nonempty prediction can pass the literal rule.

Method: fraction of this file's positive cells within Euclidean 3 px of each registry raster's positive cells, and Spearman correlation of both surfaces smoothed with a 10 px Gaussian on a 250,000-cell random subsample of the footprint. Scope: every raster in the fleet manifest that could be fetched; an unfetched raster cannot be tested, so this is not a proof of global uniqueness.

7. Limitations, irregularities and what to do next

  • Leaderboard values are not receipts. Every GEMSDOE number, including 0.2778, is owner-reported. The public leaderboard high observed on 2026-10-28 was 0.4544 (participant xiaofanhu); nothing here claims to beat it.
  • Holdout ≠ leaderboard. The holdout target is withheld catalogue faults; the leaderboard target is expert-mapped faults absent from the catalogue. A file can score well on one and poorly on the other. The estimate above is a projection with leave-one-out error, not a score.
  • Quadrant folds are unbalanced (fold 0 holds 48 % of the catalogue pixels), so the pooled metric is dominated by one fold; per-fold DTIs are reported in the evidence file.
  • The emitted field is a supervised re-detection. Because the model is trained on the catalogue, its corridors sit near known traces (63.5 % of emitted cells are within 3 px of the catalogue) and the scorer masks those pixels exactly. Suppressing that collar and re-measuring is the single highest-value next experiment; it was not applied here because it was not validated within the budget.
  • Data irregularities flagged. The official sample_submission.tif mirror is not an all-zero template: it carries exactly the 60,988 catalogue positives, contradicting the problem statement's “sample submission that predicts total fault absence”. labels.tif and existing_faults.tif are byte-identical. Both files are hash-pinned and cross-corroborated by two independent repositories, but neither is authenticated against the login-gated organizer download.
  • Weekly slot economics. The rules allow up to three submissions per week; this session spent none. Submitting is a separate decision.
