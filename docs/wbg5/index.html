What exactly is being submitted

Values are exactly 0.0 or 1.0 (150,000 cells at 1.0, all other cells 0.0), finite everywhere, no NaN. 0 dots fall on a mapped USGS/INGENIOUS catalogue pixel. SHA-256 ea7c1b1d39a858676665f6d4d575249791e40d514cc52ae63de4817a65956c27, 502,962 bytes. ZIP SHA-256 c831d7c73d83c15bdb715e9e0f9292efcb0d60fa0354b696e0b9dfcbe3a2a3fe. Portal note (105 chars, limit 140): SGMC-trained unmapped-fault prior + detrended topography; 150k dots at 300 m spacing, known faults masked.

Why the file is all-zero-and-one: the metric is distance-weighted and rewards any positive prediction near a hidden fault pixel. A binary dot raster at 300 m spacing is the budget-controlled form used by every public leaderboard file; continuous surfaces were rejected by this repository's registry gate and by the earlier portal error “Predicted values must be in range [0, 1]”.

Method

One lane, no private fork: shared feature stack, shared evaluator, shared writer.

WBG5

Prior surface P = 0.6 × SGMC fault-likeness + 0.4 × detrended-topography percentile. The SGMC model is a HistGradientBoosting classifier (41 features: the 19 organizer bands, 11 lidar scarp bands, 8 radiometric bands, distance-to-catalogue, distance-to-springs, distance-to-vents) trained only on the independent USGS State Geologic Map Compilation structure layers for NV/CA, with negatives more than 300 m from any SGMC fault. It never sees the competition labels. The topography term is the mean percentile of det_elev and det_elev_slope. Dots are a score-ordered Poisson-disk sample (3 px = 300 m minimum spacing) inside the footprint and outside the mapped catalogue.

Named non-fault mimic: Fluvial terrace risers, landslide headwalls, Lake Lahontan shorelines, road cuts and lithologic contacts produce the same topographic steps and would be false positives.

Spatial validation: 4-quadrant out-of-fold model, fold AUC 0.773 / 0.805 / 0.789 / 0.790, pooled 0.792 (no single feature above 0.62, so the leakage canary at 0.90 is not tripped). The DTI curve uses out-of-fold scores only.

Why GEMSDOE32 B2 reports 0.2778

Measured subset arithmetic, then an explicitly labelled inference.

forensics

Measured. B2 (37,654 dots, user-reported 0.2778) is a strict subset of GEMSDOE25 D2.8 (44,090 dots, user-reported 0.2600). The 6,436 dropped dots all sit 1–2 px from a mapped catalogue pixel (3,891 ≤1 px, 2,545 at 1–2 px); B2's nearest dot to the catalogue is 2.236 px away. No surface changed — only the dot set did.

Inference (labelled as such). The official mask removes exact known-fault pixels, with no buffer. A dot in the 1–2 px collar therefore still competes: it earns TP only if an unmapped truth pixel lies within 3 px, and otherwise pays the full false-positive weight. Removing those dots raised the reported index, which is what happens when they were net false positives. The opposite hypothesis — that a scored collar of new fault pixels surrounds every mapped fault — predicts the removal should have lowered the index. It did not, so the evidence favours “dead weight”, not “a better surface”.

Can we beat it? Not by resubmitting that family: B2 is already the same dots minus their dead weight, and GEMSDOE36 (B2 plus 1,200 dots) reports 0.2750, slightly lower. On an independent truth set our surface scores 1.64× B2 at B2's own dot budget. Whether that transfers to the organizer index is not measurable offline; no absolute score is projected here.

What this is not

Limits a reader must apply before spending a weekly slot.

honesty
  • Not an organizer score. No local harness reproduces the organizer mask of all USGS/INGENIOUS pixels, so SGMC-PROXY-DTI cannot be converted into a leaderboard value. No absolute score is projected.
  • Supporting holdout is weaker than the primary evidence. Under hide-and-recover of whole catalogue segments the scarp+topography blend reaches 10.37% at 150k versus 9.02% for random; the SGMC term is excluded from that harness because its distance feature uses the full catalogue.
  • Transfer risk. If the hidden new-fault set is short splays rather than long structures, the SGMC-trained signature may transfer less well.
  • The public subset is unknown. Only predictions inside it are scored, and the file over-covers the whole footprint.
  • A local pass is not a portal receipt. Upload once and keep the receipt; if the portal rejects the bytes, that receipt outranks every number on this page.
