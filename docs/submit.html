5 · Why there is no local score estimate: the inversion finding

MEASURED NEGATIVE RESULT Scoring all 13 registry rasters with the unchanged shared hide-and-recover evaluator gives a rank correlation with their owners' reported scores of -0.849 (n = 9). The instrument is anti-predictive.

  • PRIVILEGED-CATALOGUE BIAS: registry rasters were built with the FULL mapped catalogue, and the proxy truth is a random 20% subset of that same catalogue, so catalogue-hugging dots score as direct hits here. The live truth is disjoint from the catalogue, so those dots are false positives there. This makes cross-family comparison on this instrument invalid.
  • SHELL BIAS: the shared split forces withheld truth to lie >=3.16 px from visible catalogue, so proxy truth piles up in a thin shell around mapped traces; the detached-* instruments narrow truth to pixels far from any visible trace to reduce it.
  • Fold-local candidates (this lane) never see the withheld components, so their numbers are not inflated by the privileged-catalogue bias; registry rasters' numbers are.

Decisive counterexample. GEMSDOE32 is GEMSDOE25 with every dot within 2 px of the catalogue removed. Reported leaderboard went 0.2600 → 0.2778 (pruning helped). On this instrument the same pruning collapses pooled DTI 0.0919 → 0.0037 and coverage 0.142 → 0.005. The instrument ranks those two files in the opposite order to the organiser-adjacent numbers. Narrowing truth to pixels far from any visible trace (detached-6px, detached-8px) does not repair it:
