Corrections and limitations

  • orientation defect: The v1 abs(cos(2*delta)) feature rated perpendicular and parallel edge normals equally coherent. v2 uses cos-squared alignment; old model/holdout statistics do not describe v2.
  • cache defect: v1 reused outputs based on file existence alone. v2 binds feature implementation, raw inputs, footprint and output bytes in a manifest.
  • canary caveat: AUC <=0.90 is necessary under the protocol, not proof that leakage is absent.
  • preplacement defect: The historical script placed dots before its registry comparisons and wrote a research TIFF after the duplicate stop; it is now guarded before any run.
  • detached diagnostic caveat: Same OOF predictions were rescored under different segment masks without refitting; not an independent confirmation.
  • metadata caveat: Band 6 values inconsistent with unscaled tilt radians support a radiometric interpretation but do not prove channel identity or units. Band 15 is not authenticated geological basement.
  • publication correction: The former rendered hypotheses invented heat_flow and other band indices absent from this stack. The renderer now uses the actual 19-band receipt and source operator names.

The shared evaluator and writer remain pinned and unchanged; these corrections affect a local scientific feature, its cache safety and publication claims. The campaign entry point is guarded before data/model/evidence writes because no method lane is currently assigned.
