Band metadata caveat

In the owner mirror, the band-6 description says tilt angle or total curvature, while the organizer page illustrates a radiometric tc layer. Reproducible mirror measurements find 3,073 masked sentinels and 5,164,300 valid cells with no negative valid values. That does not establish band identity or units. The depth band's official description says conductive-base depth; the mirror calls it basement depth, which is not sufficient evidence to reinterpret it as geological basement. No authenticated metadata has reconciled either disagreement.
