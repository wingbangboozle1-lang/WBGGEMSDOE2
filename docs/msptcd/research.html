Decision · negative

DO NOT SUBMIT the archived MSPTCD raster.

Its dots overlap the registered binary lattice by 100% within 3 pixels. The complete registry and source pre-placement gate were not validated. No approval is implied by a format check.

What the historical code implements

The inspected module combines 19 owner-mirrored bands with 12 operators: potential-field tilt gradients, depth-proxy shifted magnetic/gravity concordance, electrical flank differences, topographic Hessian ridges, total-count/terrain residuals, conductive-base steps, gradient orientation coherence, strain and seismicity indices. These are already implemented ideas, not the new shortlist.

Mirror metadata and the official description disagree on band 15: use the term conductive-base depth, not an assumed basement depth. The official feature inventory describes tc as radiometric total count while mirror band metadata describes tilt/curvature; value distributions are suggestive but cannot authenticate physical units or origin.

Lithologic contacts, dikes, acquisition striping, surface cover, shorelines and anthropogenic features can mimic fault signals. Neither a gradient nor a canary pass is proof of a previously unmapped fault.
