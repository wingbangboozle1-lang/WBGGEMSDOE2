Method and metric

Fault predictions are evaluated using pooled distance-weighted Tversky (α=0.2, β=0.8) with a 300 m triangular kernel. This metric description is not a leaderboard prediction. Known catalogue pixels are excluded, but a surrounding neighborhood is not confirmed excluded.

Use buffered whole-segment holdouts, derive catalogue features from visible faults only, run feature-alone canaries and compare with a matched incumbent using the pinned shared evaluator. Canary passes cannot prove absence of leakage. A separate selector checks the real quota.
