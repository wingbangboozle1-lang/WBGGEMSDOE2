Fleet files used for measurement

93 submissions across 55 owner sites were downloaded through the GitHub API and hash-checked (data_public/raster_fetch_manifest.json), plus the nine pinned focus files verified against registry/focus_sites.json (data_public/focus_pins_verified.json, all nine SHA-256 matches). The organizer-format inputs are pinned in data_public/official/SOURCES.json: existing_faults.tif = labels.tif = 7ba308cc…ae4093, sample_submission.tif = 2176d08e…d35cbc.

Two irregularities for review.

  1. The fleet's labels.tif is byte-identical to its existing_faults.tif (same SHA-256), i.e. the file labelled "labels" is the visible catalogue, not the hidden scoring labels. Any "holdout DTI" or "catalogue proxy" computed from it measures agreement with the catalogue, not with the competition's target.
  2. training_features.tif (the 419 MB, 19-band stack the fleet's pipelines describe) is not present in any repository checked and cannot be downloaded without DrivenData authentication. Results that depend on it are therefore not reproducible from these pages, including our own hypotheses 2–4.
