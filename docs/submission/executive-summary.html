How to submit — only after a separate approval exists

  1. Check the current run card and the exact candidate release record. Continue only when it explicitly says OK TO DOWNLOAD AND SUBMIT, names the file and SHA-256, and records a passing validator, holdout and complete-registry checks.
  2. Do not treat a score estimate, projection, local format pass, or this historical table as approval. A holdout must beat a matched incumbent under the pinned evaluator and include the evaluator version, withheld positives and 95% CI.
  3. Download the exact approved GeoTIFF (or a ZIP containing exactly one GeoTIFF) and verify its SHA-256. Current project specifications require matching CRS, shape and geotransform, one band, and predictions in [0,1]. The validator must check NaNs and masks against the footprint, not silently clip or repair.
  4. On the official DrivenData competition page, open Submit → Make new submission, choose the exact approved file, and paste the short release note (≤140 characters). Check the live weekly allowance and current rules; the project does not automate upload or choose a slot.
  5. Save the submission-page receipt. Only that receipt can support the label ORGANIZER-CONFIRMED. A public leaderboard entry alone is not a receipt for a particular file.
