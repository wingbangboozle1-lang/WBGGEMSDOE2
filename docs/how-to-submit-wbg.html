Verify the file before uploading

Check that the downloaded file matches these specifications:

  • Format: Single-band GeoTIFF (.tif)
  • CRS: EPSG:32611 (UTM Zone 11N)
  • Resolution: 100 m
  • Shape: 3730 × 3292 pixels
  • Transform: [100.0, 0.0, 243350.0, 0.0, -100.0, 4508550.0]
  • Data type: float32
  • Values: All in [0, 1] inside the footprint
  • No NaN: Inside the scored footprint
  • Outside footprint: Set to 0.0
3

Submit on DrivenData

  1. Sign in to DrivenData GEMS Prize competition
  2. Navigate to the submission page
  3. Click File to submit and select your .tif file
  4. Enter a note (optional, max 140 characters). Suggested: "Near-fault geophysical dot clusters for blind geothermal fault discovery"
  5. Click Submit
❗ Important notes:
  • A local format check is not organizer acceptance. The DrivenData portal may reject files for reasons not visible locally.
  • If you see "Predicted values must be in range [0, 1]", it typically means NaN or out-of-range values appear where the portal reads them. This file uses 0.0 outside the footprint to avoid that issue.
  • Keep the organizer submission receipt as your score of record. A local HOLDOUT-DTI is not a leaderboard score.
  • Check your remaining weekly submission allowance on the submission page.
4

After submission

  • Record the exact filename, SHA-256, note, and timestamp
  • Wait for the organizer to process and display your score on the leaderboard
  • Compare your organizer-confirmed score against the HOLDOUT-DTI estimate of 0.2879
  • Check the public leaderboard for your ranking
